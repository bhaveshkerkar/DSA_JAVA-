## 🧠 My Learning Approach

For each problem, I try to focus on:

1. Understanding the problem
2. Identifying the important constraints
3. Developing a basic approach
4. Finding a better or optimized approach
5. Understanding the algorithm
6. Analyzing time complexity
7. Analyzing space complexity
8. Testing edge cases

Whenever possible, I compare different approaches to understand **why one solution is better than another**.
